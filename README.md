# WireLink Studio（物联接线台）

浏览器端工业设备接线图编辑器。先绘制单根导线，再将连接同一对设备的导线组成可折叠线束。工程保存在本机文件中，无需后端或账号。

- [CHANGELOG.md](./CHANGELOG.md)：版本变更。
- [ISSUES.md](./ISSUES.md)：问题记录与当前限制。

## 运行应用

要求 Node.js 22.12+（22.x）、24.x 或 26.x 及更新版本，并安装 npm。

在项目目录执行：

```bash
npm ci
npm run dev
```

使用终端显示的本地地址打开应用。如需检查可交付构建，执行 `npm run build`；构建文件在 `dist/`，可用 `npm run preview` 本地预览。

应用在浏览器中运行，没有账号、云端同步或自动保存。离开页面前请显式保存工程文件。

## 创建工程与资料库

1. 在欢迎页输入工程名称，点击“新建工程”；也可点击“打开工程”读取 `.wlproj` 或 `.json` 文件。
2. 在左侧“端子类型”中新增类型，设置名称、颜色与兼容类型。连接要求两端**互相**声明兼容；端子还受最大连接数限制。
3. 在“设备模板”中新增设备，设置名称、分类、宽高、四边端子及端子顺序。可选用 PNG/JPG/WebP 图片，单张不超过 5 MB；图片会内嵌到工程文件。
4. 点击“放入画布”或把模板拖到画布。选中设备后，可在右侧改名、设置宽高、复制或删除。

画布网格间距为 **30 个画布单位**。设备位置和宽高按网格对齐，四角与端子中心落在网格点上；同一边相邻端子间隔 30 单位。可使用画布左下方控件缩放、适配视图，拖动画布空白区域平移。

## 绘制与编辑单根导线

1. 点击起点端子。
2. 按需要点击画布添加路径点；点击位置会吸附到最近的网格点。相邻点直接连接，因此可以绘制斜线。
3. 点击终点端子完成连接。创建时会检查端子类型、容量和重复连接。

走线过程中，按 `Backspace` 撤回上一个路径点，按 `Esc` 取消。新导线默认以起点端子名称命名，标签位于整条路径的长度中点。

点击导线后可在右侧修改线号、名称、颜色和备注。选中的路径点可拖动；右键线段可在最近的网格点添加路径点，右键路径点可删除。右键导线还可打开属性或删除导线。画布采用右键菜单处理路径编辑；双击导线保留给所属线束的折叠/展开操作。

## 创建与编辑线束

1. 先分别完成至少两根单根导线。它们必须连接**同一对设备**，且尚未属于其他线束。
2. 在画布上按住 `Ctrl` 逐根点击这些导线，再在其中一根上右键选择“创建线束”。
3. 填写线束名称、编号、颜色、线缆型号等信息，进入“线束走线”。
4. 第一次点击网格设置第一侧汇合点，之后每次点击追加临时路径点，画布会实时预览折线。至少再点击一个不同的网格点，在画布聚焦时按 `Enter` 完成：最后一个临时点成为第二侧汇合点，其余点成为共用主干路径点。`Backspace` 删除最后一个临时点，`Esc` 取消走线。聚焦“取消”按钮并按 `Enter` 会取消走线。

原导线仍是实际芯线，端子、名称、颜色及展开路径均保留。方向相反的导线只在折叠视图中统一显示方向，不改动实际连接。折叠视图的分支和主干可右键添加路径点、拖动路径点或右键删除路径点；双击线束或芯线可切换折叠与展开。在右侧“解除线束分组”会保留原有导线。

## 检查、保存与导出

- 底部“校验”显示接线问题；点击可定位的问题可选中相应对象。“端子接线表”和“线束明细表”可搜索，端子接线表可导出 CSV。
- 点击“保存”或按 `Ctrl+S` 保存自包含的 `.wlproj` 工程。支持文件系统选择器的浏览器会写入所选文件；其他浏览器会下载工程文件。撤销为 `Ctrl+Z`，重做为 `Ctrl+Y` 或 `Ctrl+Shift+Z`。
- 顶部“导出”支持工程 JSON、SVG、PNG 和离线 HTML 查看页。SVG、PNG、HTML 遵循当前线束折叠状态。HTML 查看页可直接点击画布对象选中，也可从左侧列表定位并切换线束状态。
- “打印 / PDF”通过浏览器打印对话框保存为 PDF；若工程中存在已完成走线的线束，会生成折叠总览与展开明细两页，否则生成一页。

## 工程文件与常见提示

应用版本 `0.2.0` 与工程文件结构版本 `3` 是不同编号。当前只读取结构版本 `3` 的工程文件；旧结构文件不会自动迁移。工程文件包含资料库、设备、导线、线束、图片资产和视图偏好，建议保留 `.wlproj` 原件作为可编辑备份。JSON 导出是同一工程数据的副本。

若无法完成连接，请检查两端端子类型是否互相兼容、是否达到连接上限，以及这对端子是否已有导线。若线束不能创建，请检查是否至少选择两根导线、是否连接同一对设备，以及它们是否已属于线束。PNG 和 PDF 的生成依赖浏览器的图片编码与打印能力。
