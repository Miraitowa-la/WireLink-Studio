# WireLink Studio（物联接线台）

浏览器端工业设备接线图编辑器。先绘制单根导线，再将连接同一对设备的导线组成可折叠线束。工程保存在本机文件中，无需后端或账号。

- [CHANGELOG.md](./CHANGELOG.md)：版本变更。
- [ISSUES.md](./ISSUES.md)：问题记录与当前限制。

## 运行应用

要求 Node.js 22.12+（22.x）、24.x 或 26.x 及更新版本，并安装 npm。

在项目目录执行：

```bash
npm ci
npm run dev
```

使用终端显示的本地地址打开应用。如需检查可交付构建，执行 `npm run build`；构建文件在 `dist/`，可用 `npm run preview` 本地预览。

应用在浏览器中运行，无需账号，也不提供云端同步。未保存的工程会在本机浏览器中自动保存为草稿；下次打开时可从欢迎页草稿列表选择恢复。草稿不会写入 `.wlproj` 文件，重要工程仍应使用“保存”按钮手动保存。

## 创建工程与资料库

1. 在欢迎页输入工程名称，点击“新建工程”；也可点击“打开工程”读取 `.wlproj` 或 `.json` 文件。
2. 在左侧“端子类型”中新增类型，设置名称、颜色与兼容类型。连接要求两端**互相**声明兼容；端子还受最大连接数限制。
3. 在“设备模板”中新增设备，设置名称、分类、宽高、四边端子及端子顺序。可选用 PNG/JPG/WebP 图片，单张不超过 5 MB；图片会内嵌到工程文件。
4. 点击“放入画布”或把模板拖到画布。选中设备后，可在右侧改名、设置宽高、复制或删除。

画布网格间距为 **30 个画布单位**。设备位置和宽高按网格对齐；模板宽高留空时按端子数量自动适配，填写时作为期望尺寸，必要时仍会扩大以容纳端子。端子中心只落在 30 单位网格点上，同一边相邻端子间隔 30 单位，首尾端子到边角至少留 60 单位。对边端子数量一奇一偶时，较少的一边会在网格上尽量居中。可使用画布左下方控件缩放、适配视图，拖动画布空白区域平移；走线时用鼠标中键平移。

右键点击空白画布可切换导线／线束名称、设备名称和设备图片的显示，也可一次展开或折叠所有已走线的线束。显示设置随工程保存并用于图纸导出；隐藏名称不会清除已调整的位置，隐藏图片不会改变设备尺寸或端子。批量展开／折叠可一步撤销。

## 绘制与编辑单根导线

1. 点击起点端子。
2. 按需要点击画布添加路径点；点击位置会吸附到最近的网格点，已有导线上也可加点。相邻点直接连接，因此可以绘制斜线。
3. 点击终点端子完成连接。创建时会检查端子类型、容量和重复连接。

走线过程中，按 `Backspace` 或 `Ctrl+Z` 撤回上一个路径点；没有临时点时，`Ctrl+Z` 不撤销工程。按 `Esc` 取消走线。新导线默认以起点端子名称命名，标签位于整条路径的长度中点。

点击导线后可在右侧修改线号、名称、颜色和备注。选中的路径点可拖动；右键线段可在最近的网格点添加路径点，右键路径点可删除。右键导线还可打开属性或删除导线。画布采用右键菜单处理路径编辑；双击导线保留给所属线束的折叠/展开操作。

导线名称可直接拖动，名称中点会吸附到 30 单位网格点；右键名称可选择“复位名称位置”。未拖动的名称保持默认位置。拖动只改变标签位置，线路仍按原路径绘制；线路移动或修改后，标签保持相对偏移。

## 创建与编辑线束

1. 先分别完成至少两根单根导线。它们必须连接**同一对设备**，且尚未属于其他线束。
2. 在画布上按住 `Ctrl` 逐根点击这些导线，再在其中一根上右键选择“创建线束”。
3. 填写线束名称、编号、颜色、线缆型号等信息，进入“线束走线”。
4. 第一次点击设置第一侧汇合点，之后每次点击追加临时路径点，画布会实时预览折线；已有导线上也可加点。线束路径点吸附到最近的 15 单位位置。至少再点击一个不同的位置，在画布聚焦时按 `Enter` 完成：最后一个临时点成为第二侧汇合点，其余点成为共用主干路径点。`Backspace` 或 `Ctrl+Z` 删除最后一个临时点；没有临时点时，`Ctrl+Z` 不撤销工程。`Esc` 取消走线。聚焦“取消”按钮并按 `Enter` 会取消走线。

原导线仍是实际芯线，端子、名称、颜色及展开路径均保留。方向相反的导线只在折叠视图中统一显示方向，不改动实际连接。折叠视图的分支和主干可右键添加路径点、拖动路径点或右键删除路径点；双击线束或芯线可切换折叠与展开。在右侧“解除线束分组”会保留原有导线。

折叠线束名称按中点吸附到 15 单位位置，可放在两个网格点之间，并可通过名称上的右键菜单复位。名称位置随工程保存；画布、SVG、PNG、打印图纸及离线 HTML 查看页使用同一位置。

## 检查、保存与导出

- 底部“校验”显示接线问题；点击可定位的问题可选中相应对象。“端子接线表”“从／到接线清单”和“线束明细表”均可搜索并导出当前筛选结果为 CSV。线束明细 CSV 包含线束编号、芯线、两端设备/端子、状态和备注。
- 导出按钮显示“导出当前筛选结果（N 条）”，条数随当前报表和搜索结果更新；切换报表会保留搜索词，需要完整清单时请先清空搜索框。
- “从／到接线清单”每根导线一行，包含从设备、从端子、到设备、到端子、线号、导线名称、所属线束、线束编号及导线备注。“从／到”采用实际连接的起点／终点，不表示电流方向；线束折叠时全部芯线仍列出。点击“从设备”可定位导线；缺失的设备、端子或线束会保留其 ID，便于排查引用问题。
- 点击“保存”或按 `Ctrl+S` 保存自包含的 `.wlproj` 工程。支持文件系统选择器的浏览器会写入所选文件；其他浏览器会下载工程文件。普通状态下，撤销为 `Ctrl+Z`，重做为 `Ctrl+Y` 或 `Ctrl+Shift+Z`；走线期间暂停工程撤销和重做。删除快捷键只在画布获得焦点时生效；`Esc` 优先关闭编辑弹窗，再依次关闭右键菜单、取消走线和取消选中，每次只退出一层。
- 顶部“导出”支持工程 JSON、SVG、PNG 和离线 HTML 查看页。SVG、PNG、HTML 遵循当前线束折叠状态。HTML 查看页可直接点击画布对象选中，也可从左侧列表定位并切换线束状态。
- “打印 / PDF”通过浏览器打印对话框保存为 PDF；若工程中存在已完成走线的线束，会生成折叠总览与展开明细两页，否则生成一页。

选中设备、导线或线束后，画布会突出直接相关的对象，并将其余对象变淡；点击其他对象立即切换，点击空白处取消。只计算一跳连接。折叠线束不会因为选中芯线而自动展开。离线 HTML 查看页支持相同操作；普通 SVG、PNG 和打印图纸不带临时突出效果。

## 工程文件与常见提示

应用版本 `0.4.5` 与工程文件结构版本 `5` 是不同编号。新建及保存的工程写为 v5，包含导线和线束名称的相对位置。开发阶段仅支持读取 v5 工程，不再迁移旧结构；需要保留的旧工程请在升级前用旧版应用备份。工程文件包含资料库、设备、导线、线束、图片资产和视图偏好；JSON 导出是同一工程数据的副本。

修改工程后，应用会在约半秒内将未保存版本自动写入当前浏览器的 IndexedDB，并在页面关闭时尝试立即写入。各编辑会话分别保存草稿，保存或放弃当前工程只清理当前会话的草稿，不影响其他标签页。欢迎页的“本机草稿”列表按保存时间列出所有未被其他标签页占用的草稿，可选择任意一份恢复；“暂不恢复”只收起列表，之后可点击“查看本机草稿”重新查看，“刷新草稿列表”用于重新检查已关闭的标签页。无效草稿会显示原因，不会自动删除。

恢复会先保存独立副本，再打开工程，不覆盖原草稿或 `.wlproj` 文件。原草稿继续保留；确认不再需要后，在欢迎页点击对应的“删除草稿”并确认删除。删除只处理该条草稿，且无法撤销。浏览器下载式保存无法确认文件已落盘，因此会继续保留恢复草稿并显示提示。浏览器清理站点数据、隐私模式或存储空间不足都可能使草稿不可用；界面会显示草稿保存状态。恢复的草稿需要重新手动保存为 `.wlproj` 文件。

若无法完成连接，请检查两端端子类型是否互相兼容、是否达到连接上限，以及这对端子是否已有导线。若线束不能创建，请检查是否至少选择两根导线、是否连接同一对设备，以及它们是否已属于线束。PNG 和 PDF 的生成依赖浏览器的图片编码与打印能力。
